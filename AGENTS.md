# Regras de Comportamento do Projeto (FtM Chartbook)

## Modos de Operação

### 1. Plan Mode (Modo de Planejamento)
- Quando o usuário solicitar planejamento ou usar `/plan`, sempre:
  1. Analisar a estrutura do repositório e os impactos das mudanças.
  2. Apresentar um plano detalhado com arquivos afetados, etapas de implementação e validação.
  3. Aguardar confirmação do usuário antes de realizar alterações estruturais profundas.

### 2. Auto Mode (Modo de Execução Autônoma)
- Para tarefas diretas, correções de bugs, ajustes de código ou tarefas aprovadas:
  1. Proceder de forma autônoma com leitura, escrita e execução dos comandos necessários (como `git`, `npm`, scripts).
  2. Manter integridade do código, boas práticas e estilo minimalista do projeto.
  3. Testar e validar as mudanças antes de concluir.
